# Magic Mayer Home-Made Pedal (MMH-MP)

Home-made guitar gear, built one step at a time. Three famous pedals (Tube Screamer, Klon Centaur, Keeley Katana) are recreated: first as code you can hear on the PC, then on a small computer chip, then as real circuits. A wireless link replaces the guitar cable.

Plan: [docs/plan.md](docs/plan.md). Everything to buy, with prices: [shopping-list.md](shopping-list.md).

## Tone Lab: hear it on the PC first

A desktop app that plays your guitar through the effects in real time. Turn the real knobs, compare with a recording of a real Tube Screamer, and save presets. The pedal chip runs the same code, so what you tune here is what you get. Done. [tone-lab/](tone-lab/readme.md)

## 1. Wireless guitar system

A small battery box plugs into the guitar and sends the sound by radio to a second box at the amp, headphones or audio interface. About 4-5 ms of delay. Next to build. [wireless-guitar-system/](wireless-guitar-system/readme.md)

## 2. Digital pedal

One pedal box where an ESP32 chip plays all three effects, with the real knobs and a footswitch for each effect. [digital-pedal/](digital-pedal/readme.md)

## 3. Analog pedals

The same effects as real circuits of op-amps, diodes and transistors, one box each, to compare with the digital pedal. Postponed. [analog-pedals/](analog-pedals/readme.md)
